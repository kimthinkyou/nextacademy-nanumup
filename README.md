# 청년공유콘텐츠 업(UP)

"내가 만들고, 함께 다듬다" — 중장년의 전문지식과 경험을 청년·청소년을 위한 콘텐츠로 함께 만들고 다듬는 커뮤니티의 소개·회원 모집 페이지입니다.

## 배포 주소

- 사이트: https://dazzling-jelly-a50d0c.netlify.app/
- 회원 모집 탭 바로가기: https://dazzling-jelly-a50d0c.netlify.app/#recruit

주소 끝에 `#intro`, `#org`, `#plan`, `#recruit` 를 붙이면 해당 탭이 바로 열립니다.

## 구성

- `index.html` — 단일 HTML 파일 (모바일·데스크톱 반응형, 외부 의존성은 폰트·아이콘 CDN뿐)
- 가입 신청서는 [Web3Forms](https://web3forms.com)를 통해 운영진 메일(kimthinkyou@gmail.com)로 전송됩니다.

## 수정 후 다시 배포하기

`index.html` 을 고친 뒤 Netlify 사이트 관리 화면의 **Deploys** 탭에 폴더(또는 파일)를 끌어다 놓으면 같은 주소로 갱신됩니다.
